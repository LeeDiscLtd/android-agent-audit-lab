1. Java/Kotlin JVM 目标版本不一致：统一到17。

- 本次证明靶标和独立核验流程可用，不证明越权检测准确率或在线阻断效果；尚未接入智能体。
- 下载走本机 HTTP + ADB 转发。有效载荷字节不是移动网络计费流量；文件逻辑长度可能包含预分配。
- 日志记录下载结果被观察到的时间，不是精确下载结束时刻。普通系统时钟不是第三方可信时间戳。
- target.v1 是本地 schema，还没有团队 C1 最终 schema 的兼容性确认；未实现签名、哈希链或崩溃原子性保证。
